# Amalfi brand assets

Shared visual resources for Café Amalfi Flutter applications. The package keeps
one source of truth for the logo, backgrounds, application icons, SVG icons,
the dashboard coffee photograph, and light/dark PNG fallbacks.

`AmalfiIcon` applies the active theme's color to branded interface icons.
The coffee photograph is reserved for the blurred, low-opacity background; it
must not be used as an operational surface or obscure interface content.
