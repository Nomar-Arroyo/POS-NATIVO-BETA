# Café Amalfi — Gerencia móvil

Esta carpeta reserva el espacio para la futura aplicación móvil del gerente.
Compartirá los paquetes de negocio y recursos Flutter que correspondan; no debe
duplicar cálculos comerciales ni conectarse a Supabase hasta que ese servicio y
el alcance funcional estén aprobados.

La carpeta todavía no contiene una aplicación ejecutable. El diseño y las
funciones móviles se incorporarán en una etapa independiente, sin afectar la
Beta ni la aplicación Desktop.
